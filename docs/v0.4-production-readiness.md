# v0.4 — Production Readiness

**Date:** 2026-03-18

## What was done

Hardened the project for production deployment: improved graceful shutdown, added per-IP rate limiting, optimized Docker image, created a Helm chart, and added integration tests.

### Graceful shutdown improvements

**Files:** `cmd/hookman/main.go`, `internal/api/server.go`, `internal/api/health.go`, `internal/config/config.go`

- Added `SHUTDOWN_TIMEOUT` config (default 30s) — separate from `REQUEST_TIMEOUT`
- Added `/ready` endpoint (alias of `/health`) for Kubernetes readinessProbe
- Health and ready endpoints return `503 {"status": "shutting_down"}` once shutdown is signaled
- Shutdown flow now includes a 5-second grace period for load balancers to drain before stopping workers

**Shutdown sequence:**
```
SIGINT/SIGTERM received
  → NotifyShutdown()          # /health and /ready return 503
  → 5s grace period           # LB stops routing new traffic
  → cancel context            # poller and workers stop accepting new work
  → HTTP server shutdown      # drains in-flight HTTP requests (up to SHUTDOWN_TIMEOUT)
  → worker pool stop           # waits for workers to finish current jobs
```

### Rate limiting

**Files:** `internal/api/ratelimit.go` (new), `internal/api/server.go`, `internal/config/config.go`

- Per-IP token bucket rate limiter using `golang.org/x/time/rate`
- Configurable: `RATE_LIMIT_RPS` (default 100), `RATE_LIMIT_BURST` (default 200)
- Set `RATE_LIMIT_RPS=0` to disable rate limiting
- Returns `429 Too Many Requests` when limit exceeded
- Background cleanup goroutine evicts stale IP entries every 5 minutes (idle > 10 min)
- Applied to `/api/*` routes only (before auth middleware)

## Key decisions

| Decision | Rationale |
|----------|-----------|
| **Separate `SHUTDOWN_TIMEOUT`** | Request timeout (10s) is too short for graceful drain. 30s default matches K8s `terminationGracePeriodSeconds` |
| **5s grace period before drain** | Gives load balancers time to stop routing after `/health` returns 503 |
| **Per-IP rate limiting** | Simple, effective for API abuse prevention. No external dependency needed |
| **`golang.org/x/time/rate`** | Standard library quality, token bucket algorithm, already an indirect dep |
| **Rate limit on /api only** | Dashboard and health endpoints should always be accessible |
| **`//go:build integration` tag** | Integration tests require a real database — don't run in CI without postgres |
| **Non-root Docker user** | Security best practice — limits blast radius of container escape |
| **Helm chart without bundled Postgres** | Users bring their own database — keeps chart simple and production-appropriate |
| **Init container for migrations** | Runs migrations before the main container starts — safe for rolling deployments |
